## 🚀 核心功能

### 1. 思维导图编辑与可视化增强

#### 交互式编辑与核心布局
- ✅ **可视化编辑**: 直接在 Obsidian 中创建与编辑思维导图，支持流畅拖拽、快捷键操作、所见即所得与完整的撤销/重做（`Ctrl+Z` / `Ctrl+Y`）历史
- **4 种全局布局方向**: 居中分布、右侧分布、左侧分布、顺时针分布
- **13 套内置主题与调色**: 7 种专业主题 + 6 种多巴胺配色，搭配智能节点连线颜色系统与画布背景选择器
- **响应式画布**: 自动适应视口与内容尺寸，流畅缩放与平移

#### 全面丰富的富文本与嵌入渲染
| 内容类型 | 支持功能与具体表现 |
|---------|---------|
| **Markdown 语法** | 粗体、斜体、高亮、删除线、行内代码、多级标题 |
| **表格渲染与编辑** | 完整表格可视化渲染与节点内编辑，支持转换为对比矩阵 |
| **Callout 警告块** | 支持多种 Callout 类型（NOTE、TIP、WARNING 等），自适应主题色 |
| **引用块 (Blockquote)** | 原生引用块渲染、长文本块引用展示 |
| **代码块 (Codeblock)** | 语法高亮着色，支持作为子节点独立渲染 |
| **嵌入内容 (Embeds)** | 完美嵌入渲染 Canvas、PDF++、Eagle、Excalidraw 等画板与媒体 |
| **双向链接 (Wikilinks)** | 原生 Obsidian `[[笔记双链]]` 跳转与反向引用 |
| **数学公式与脚注** | LaTeX 数学公式渲染、上标脚注保护，往返无损 |
| **任务列表 (Checklist)** | 原生交互式可点击复选框，联动任务状态 |

#### 视图增强与快捷设置
- **Quick Settings 快捷面板**: 画布右上角快捷悬浮条，一键切换 13 款主题、切换 4 向布局结构、调节分支连线颜色组与底色选择器
- **大纲视图**: 树状结构实时呈现、毫秒级关键词检索与双向同步滚动
- **地图概览 (Minimap)**: 画布缩略小地图、可视区高亮框、平滑拖拽与快速定位跳转
- **折叠状态持久化**: 基于 `<!--c-->` 标记，完美兼容 Workflowy 插件，重启自动还原折叠状态

### 2. 原生 XMind 引擎与专业格式互通

#### 多骨架路由与排版拓扑
- **42 款骨架布局自由切换**: 在 Frontmatter 中声明 `skeleton:`，涵盖思维导图、时间轴、鱼骨图、组织架构、逻辑图、括号图、矩阵与二维表格等 11 大族系
- **单分支局部结构混排**: 在任意分支标题末尾添加 `#layout/xxx`（或中文 `#排版/xxx`），即可让该分支独立呈现特殊结构（如鱼骨图混排思维导图），导出时自动处理
- **图标标记纯透传**: `#marker/<id>` 原样进出 XMind 图标，往返无损、容错性高，与任务态复选框互不干扰
- **Markdown 表格转二维矩阵**: 原生 Markdown 对比表格直接编译为 XMind 2D 对比矩阵（Spreadsheet），行列维度自动对齐

#### 53 套大师配色与精细化控制
- **53 套官方离线配色**: Frontmatter 指定 `color:` 或 `theme:`，完整内置 Rainbow、Energy、Space 等 53 套离线调色板，支持 `color: 主题名/N` 主色变体
- **全局画布视觉定制**: Frontmatter 直接声明 `background`（画布底色）、`font` / `font-family`（字体）、`grid-columns`（网格列数）、`line-width`（线宽）与 `line-tapered`（渐细），写入 XMind 主题并支持导出回写
- **动态多级层级编号**: 在 Frontmatter 中声明 `numbering: arabic` 或分支使用 `#numbering/roman`；拖动调换节点顺序时编号全自动更新
- **节点手动定宽与单节点强调**: `#width/<像素>` 手动固定节点卡片宽度；行内 HTML 标签支持单节点字号与边框重点强调
- **任务项目元数据深度联动**: 兼容 Obsidian Tasks 截止日期（`📅`）与 Dataview 进度语法（`[progress:: 50%]`），打勾自动联动 XMind 原生八分位完成度图标
- **深度高保真往返互转**: 纯离线 TypeScript 引擎，38 套浅色主题对比度智能补偿，公式与 HTML 实体严格保真，最大化保留双向转换细节与排版层次

## 📖 使用指南

### 1. 快速上手：思维导图创建与编辑
- **新建导图**: 按 `Ctrl+P` 打开命令面板，搜索 `创建新思维导图`；或在文件树右键点击任意文件夹，选择 `新建思维导图`。

## 🛠️ 安装

### 使用 BRAT 安装（推荐）

[BRAT](https://github.com/TfTHacker/obsidian42-brat)（Beta Reviewers Auto-update Tester）允许你直接从 GitHub 安装并自动更新插件。

1. 从 Obsidian 社区插件安装 BRAT 插件
2. 在设置 → 社区插件中启用 BRAT
3. 打开 BRAT 设置，点击"Add Beta plugin"
4. 输入仓库网址：`https://github.com/springrain1/obsidian-xmind-plugin`
5. 点击"Add Plugin"，BRAT 会自动安装 SuperMind
6. 在设置 → 社区插件中启用 SuperMind

> **提示**：BRAT 会自动检查更新，并在新版本可用时通知你。

### 手动安装

1. 从 [Releases](https://github.com/springrain1/obsidian-xmind-plugin/releases) 下载最新版本
2. 解压到：`<vault>/.obsidian/plugins/obsidian-xmind-plugin/`
3. 重启 Obsidian
4. 在设置 → 社区插件中启用插件
